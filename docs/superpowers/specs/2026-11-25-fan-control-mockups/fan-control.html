Limits no curve can cross10
  • Pump: never under 50%. Built in, not editable.
  • Fans: never under 20%, never stopped.
  • Main Intake Fans: ceiling 50% in every mode (yours to change).
  • A fan whose temperature stops arriving goes to its highest allowed speed.
  • A fan that reads 0 RPM gets full speed and a warning.
What Quiet changes in light use
  • Radiator fans: about 700 RPM instead of about 1,330.
  • Pump: about 2,090 RPM instead of about 2,750.
  • Intakes: about 540 RPM instead of 1,360.
  • Exhaust: about 920 RPM instead of 2,050.
  • In a game the intakes and the exhaust are back where they are today. The radiator fans and pump rise more slowly, so the coolant runs a few degrees warmer.
