# DeadWare 0.6.6 — Release notes for every missed version

When DeadWare is several versions behind, **Updates** now shows the notes for each normal release newer than your installed version, through the offered update. Each version has its own heading, ordered newest first, so you can see all the changes you missed.

Installed/older versions and previews are excluded. If earlier notes cannot be fetched, the latest notes remain visible with an explanation. **Update & restart** still installs the latest eligible release; reading notes does not install intermediate versions.

Open **Updates → Check for updates → Update & restart** to install this release. Settings, histories and saved windows are preserved.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
