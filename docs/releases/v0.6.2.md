# DeadWare 0.6.2 — Desktop-aware navigation

Battery history now hides automatically in the sidebar and Settings when Windows reports no battery, keeping desktop PCs such as Mothership focused on their available hardware. The controls return if a battery is detected or its status is unknown. If Battery history is open when the battery is removed, the dashboard returns to Overview. Saved history and existing detached windows are preserved.

**Desktop layout** is now called **Settings**, with the same window, startup and sensor controls.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
