# DeadWare 0.5.0 preview — Lifetime battery history

Battery history records how charge falls and recovers, when charging is observed, and when Windows battery saver is active. It has Day/Week/Month/Year/All ranges, CSV export and a separate window that remembers placement and Always on top.

Saved minute observations and power/saver state changes are retained indefinitely in a separate local `battery-history.db`. Long-range charts summarize the display while keeping the original observations. History starts with this upgrade while DeadWare runs; earlier lifetime readings cannot be recovered. Missing readings and stopped monitoring remain gaps. Recording can be paused without deleting existing history, and storage use/errors are visible.

Extract the entire Windows x64 ZIP. Choose **Quit DeadWare** before replacing an existing portable installation. Settings and history remain under `%LOCALAPPDATA%\DeadWare`, outside the app folder. Keep your own backup before removing the Windows profile or resetting the device. Source-code synchronization through GitHub does not synchronize local battery databases.

Windows 10/11 x64 preview; hardware coverage varies. Battery percentage and saver state come from Windows and need no elevation. Charging/saver transitions are observed only while DeadWare is sampling. Unsigned portable build, with the .NET runtime included.
