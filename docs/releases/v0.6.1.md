# DeadWare 0.6.1 — Startup update notices

DeadWare now checks normal GitHub releases once when it starts, after monitoring is running. If a newer version is available, a dashboard notice and system-tray notification let you know. **Review update** opens the Updates page.

You still choose when to download and install an update with **Update & restart**. Nothing is downloaded or installed by the startup check. **Check for updates** remains available for another check while the app is open. Preview releases are excluded; there is no recurring polling. Failed or offline checks stay on the Updates page, and quitting cancels an unfinished startup check.

In version 0.6.0, open **Updates → Check for updates → Update & restart** to install this release when convenient. Once 0.6.1 is installed, future launches check automatically. Versions 0.5.x and earlier need a complete manual ZIP upgrade. Settings, history and saved windows are preserved.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
