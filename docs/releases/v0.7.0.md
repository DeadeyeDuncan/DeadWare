- Add **Usage history** beside Battery history, with an **Open in window** action and a remembered window. Browse **Day**, **Week** and **Month** views of CPU and GPU usage and temperature, RAM usage and network download/upload, step to earlier periods, and read minimum, average and maximum for the period from the stored minute values.
- Each chart draws the average of the recorded minutes in each slot over a shaded minimum–maximum band. Minutes without readings stay empty and partial slots are not connected, so sleep, restarts and stopped monitoring remain visible as gaps.
- See per-application download and upload totals for the period, summed by executable name across its processes, with search, a share bar, an **Other applications** row beyond the first 200 names, and a notice when recorded minutes had no per-application capture.
- Recording is on by default as **Record usage history on this device** on the page and in Settings; pausing keeps what was saved. History lives in `%LOCALAPPDATA%\DeadWare\usage-history.db`, keeps up to 400 days or 256 MiB (oldest whole days dropped first, never the current day), and is never uploaded. GPU rows are keyed by model name.
- Export the period's device minutes or application totals to a new CSV file; formula-like names are neutralized.
- History begins when 0.7.0 first runs. The six-hour live graphs and their cache are unchanged and are not copied into the new store.

Existing updater-enabled installations can choose **Updates → Check for updates → Update & restart**.
