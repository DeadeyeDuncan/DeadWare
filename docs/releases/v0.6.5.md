# DeadWare 0.6.5 — Group widget graphs by metric

The widget now groups readings as intended:

- **Usage:** CPU and selected-GPU utilization together on one percent graph.
- **Temperature:** CPU and selected-GPU temperatures together on one °C graph.

CPU keeps its CPU theme color and solid line on both charts. GPU keeps its GPU theme color and dashed line on both. Each graph has CPU/GPU current-value legends, and the shared temperature scale expands above 100°C for either device when needed.

The widget retains shared history range and GPU selection, saved history and gaps, remembered sizes/placement, Always on top, and memory/network summaries.

Open **Updates → Check for updates → Update & restart** to install this release. Settings, histories and saved windows are preserved.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
