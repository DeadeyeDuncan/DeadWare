# DeadWare 0.4.0 preview — Cooling Health

Local thermal history now survives restarts. Open **Cooling Health** to view CPU/GPU temperatures, load, package power and supported clock/fan readings over a day, week or month, or export CSV.

Save a fixed reference period from conditions you believe were normal. DeadWare compares sustained operation at similar power, load and available fan speed, explains missing coverage, and can issue optional tray warnings for persistent temperature increases. Recording is on by default; notifications are off until enabled. A reference needs at least 30 eligible minute windows after warm-up; comparison needs ten consecutive matched recent minutes.

History is local only: 30 days of minute detail and 90 days of hourly summaries by default, with retention controls and a bounded database. Cooling setups and selected sensor mappings remain separate. Use New cooling setup after hardware or cooling changes. Storage faults leave live monitoring running.

The GPU selector now appears only on Overview, not Network or other unrelated pages. Existing compact pop-outs, widget, themes, tray behavior and startup settings remain available.

This is an early-warning comparison tool, not a diagnosis or lifespan prediction. Pump, flow and coolant integrations are not included. Hardware coverage still depends on supported sensors and permissions; unavailable package power can prevent comparison while other history remains useful.

Choose **Quit DeadWare** from the tray before replacing all files with the extracted archive. Closing the dashboard alone keeps the old process running. Existing settings remain in your Windows profile. Windows x64, portable, self-contained and unsigned; this remains a preview.
