# DeadWare v0.4.2 — Remember graph history

CPU/GPU usage and temperature graphs and the combined network graph now automatically save the last **six elapsed hours**. Close DeadWare or restart Windows, and readings still within the selected range return. Downtime stays visible as a gap, and live values always come from fresh samples.

No setup is needed. Graph history is saved locally every 15 seconds and flushed on normal quit, independently of Cooling Health recording. A sudden termination can lose the latest unsaved batch. After more than six hours away, earlier readings fall outside the retained range.

Hardware metadata keeps identifiable different CPUs/GPUs from inheriting one another's history. Ambiguous identical GPUs are not restored. The cache contains graph values, not application names or packet data. Cooling Health's longer history remains separate. Existing in-memory traces from older versions cannot be recovered by this first upgrade.

Portable Windows x64 preview. Fully quit the existing app from its tray menu before replacing files. Extract the ZIP and run `DeadWare.exe`; administrator mode is needed for some temperatures and per-app network accounting, depending on hardware and drivers.
