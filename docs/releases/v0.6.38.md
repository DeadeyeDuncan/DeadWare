- CPU pump speed can now be charted the same way as GPU fan speed. Open **Settings** and turn on **Show CPU pump speed on CPU temperature graphs**.
- The pump appears as a dotted line on its own left RPM scale on the dashboard CPU temperature graph, the CPU temperature pop-out and the widget temperature graph. The joined CPU / GPU temperature pop-out keeps only the GPU fan.
- When the widget shows both the GPU fan and the CPU pump, they share the left RPM scale. The pump is blue by default; use the new CPU pump color button on the overview's CPU temperature card to change it.
- DeadWare uses a motherboard or AIO header labeled as a pump (for example `Pump Fan`), otherwise the `CPU Fan` header. Turn on **Settings → Extended sensors** and restart DeadWare to read these headers. Systems with more than one CPU are not supported.

Existing updater-enabled installations can choose **Updates → Check for updates → Update & restart**, then turn on the new setting.
