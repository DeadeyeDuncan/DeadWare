- **Overview charts adapt to the available page width.** The grid uses one column below 900 DIP, two from 900 to below 1500 DIP, and three at 1500 DIP or wider.
- **Drive cards survive reflows and duplicates.** Reflowing the grid keeps each drive's chart card and its history; two drives reporting the same serial each get their own card.
- **Status notes share a card.** Memory status and the unavailable-reading note stay together in a slim card below the charts.

This release changes the Overview layout; chart readings, pop-outs, color controls and drive monitoring are unchanged.
