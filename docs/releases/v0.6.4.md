# DeadWare 0.6.4 — Hide the update banner on Updates

The update-available banner now hides while you are on the Updates page, so **Review update** no longer appears when you are already reviewing the update. Leaving Updates restores the banner if a newer version is still available. Background status changes respect the page you are viewing.

Use **Check for updates** to refresh release information, then **Update & restart** when you want to install. Startup checks and tray notifications retain their existing behavior.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
