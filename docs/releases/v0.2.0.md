DeadWare can now start with Windows and reopen your monitoring workspace.

- **Administrator startup:** enable Start with Windows in Desktop layout. One-time Windows approval configures a task for your account; turn it off from the same page.
- **Remember open windows:** graphs and the widget left open when you exit DeadWare reopen at their saved positions, sizes and topmost settings. Individually closed windows stay closed.
- **One collector:** repeated startup or shortcut launches do not create duplicate monitoring sessions.
- **Consistent themes:** scrollbars and Windows 11 native title bars follow your selected palette in the main app, graphs and widget.

After upgrading from 0.1.0, open and arrange your preferred windows once. The older version saved positions but not which windows were open. Graph history remains in memory for each session.

Download the Windows x64 ZIP, extract the entire folder, and run DeadWare.exe. The runtime is included. Close the app before replacing files; if you move the executable to a different folder, configure startup again from that location.

This remains an unsigned portable preview. Sensor support depends on hardware, firmware, drivers and permissions. The adjacent SHA-256 file verifies the ZIP; comprehensive hardware coverage, ARM64, signing and an installer remain outside this preview.
