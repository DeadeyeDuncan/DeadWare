# DeadWare 0.6.14 — Joined CPU/GPU pop-outs

**Settings → Graph pop-outs → Join CPU and GPU graphs in pop-outs** adds an optional joined layout, like the widget. Open either CPU or GPU usage from the overview to see both devices on one usage chart. Open either temperature graph to see both temperatures together. The option is saved and starts off by default.

CPU uses its theme color and a solid line in both charts; GPU uses its own color and a dashed line. Each joined pop-out shows both current readings and device statistics. Usage shares a 0–100% scale, and temperature shares a °C scale that expands above 100°C when either device needs it.

The setting applies to new pop-outs. Existing open windows and remembered layouts keep their current form, with separate saved positions, sizes and pin choices for joined and individual graphs.

The redundant graph, Battery history and widget launch buttons have been removed from Settings. Graphs still open from the overview, Battery history from its page, and the widget from the dashboard's **Open widget** button.
