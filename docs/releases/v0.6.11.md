# DeadWare 0.6.11 — RAM usage graphs

The overview and widget now include a **RAM usage** graph on a fixed 0–100% scale, with current used/total memory shown alongside the percentage. RAM sits beside Network on the overview. The widget now has four graphs: Usage, Temperature, RAM and Network.

RAM follows the shared polling interval and history range, with up to six hours saved locally. Unknown readings and downtime remain gaps. RAM history begins with new readings after this update because earlier versions did not record it.

The RAM graph can also open in its own remembered window. The widget is taller to keep four graphs readable, and older saved widget sizes expand to its new minimum.
