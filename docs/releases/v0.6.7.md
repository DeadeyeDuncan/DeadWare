# DeadWare 0.6.7 — Network graph in the widget

The widget now includes a third **Network** graph below Usage and Temperature. Download uses a solid blue line and upload a dashed green line, with both on a shared bytes-per-second scale. Current download/upload rates appear in the graph's legend.

All three charts use the shared history range and saved graph history. CPU/GPU colors and grouping, missing-data gaps, memory/status, Always on top and remembered placement remain. The widget is taller to keep the charts readable; older saved sizes expand to its new minimum and are positioned within the available work area.

Open **Updates → Check for updates → Update & restart** to install this release. Settings, histories and saved windows are preserved.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
