# DeadWare 0.6.0 — Manual updates and rollback

The new **Updates** view checks normal GitHub releases when you click **Check for updates**. It shows the installed/published versions and release notes. **Update & restart** verifies and installs a complete package, saves your workspace/history through normal Quit, and reopens DeadWare at the same path.

**Roll back & restart** restores the previous verified installed version while keeping current settings and recordings. The first updater-enabled installation may have no rollback; a previous snapshot becomes available after an in-app update. Download/preparation can be cancelled. A separate helper applies files only after the original process exits and preserves recovery information if startup cannot be confirmed.

For the first upgrade from 0.5.x or earlier, choose **Quit DeadWare**, then extract/copy the entire 0.6.0 package into the existing app folder. Keep `DeadWare.Updater.exe` and `deadware-package.json` with the app. User data remains under `%LOCALAPPDATA%\DeadWare`.

This release also includes the battery-history work: persistent percentage/charging/saver history with Day through All history ranges, CSV export and a remembered separate window. History begins when an equipped version runs; prior readings cannot be reconstructed.

Windows 10/11 x64 portable build with the runtime included; unsigned. Future version tags publish normal releases, with no automatic checking/installation or preview channels.
