# DeadWare 0.6.3 — Widget graphs

The compact widget now shows two stacked history charts: CPU and the selected GPU. Each combines a solid usage line with a blue dashed temperature line, with small current-value legends. The left axis shows usage percent; the right shows °C and expands when temperatures exceed 100°C.

Both charts use the shared graph range, selected GPU and saved history. Missing readings and downtime remain gaps. Memory and network summaries, stale-reading status, Always on top and remembered window placement remain available.

Open the widget from **Open widget** on the dashboard or from **Settings**. Change its graph range on the dashboard or in a detached graph's options menu.

In version 0.6.0 or later, open **Updates → Check for updates → Update & restart** to install this release. Settings, histories and saved windows are preserved.

Windows 10/11 x64 portable build, with the runtime and update helper included; unsigned.
