## 0.17.13 — Less work and memory after long uptime

- **Sensor readings no longer pile up for a day.** The hardware sensor library kept its own 24-hour log of every sensor's values, which DeadWare never reads: it grew for the first day DeadWare ran (several hundred kilobytes per sensor, more at faster polling) and, once full, was trimmed on every poll. That log is now off. Sensor readings, the Sensors statistics and the six-hour graphs are unchanged; they come from DeadWare's own history.
- **Live graphs read only the range they show.** Each graph refresh walked the whole six-hour graph history for every line, whatever range was selected, so each refresh cost more the longer DeadWare had been running (up to six hours). A refresh now reads just the selected range. Smoothed 1 h, 3 h and 6 h graphs also no longer copy the whole history on every poll.

This release changes how much work and memory DeadWare uses over time; what the graphs and sensors show is unchanged.
