## 0.17.14 — Internal restructuring

- **The monitoring code now lives in its own library.** Everything DeadWare does that is not user interface (sensor reading, per-app capture, the histories, alerts and updates) moved out of the app into a separate `DeadWare.Services.dll`, which ships alongside `DeadWare.dll`. This is groundwork for the planned WinUI 3 interface.

Nothing you can see or measure changes in this release: the pages, readings, histories, settings and updater behave as in 0.17.13.
