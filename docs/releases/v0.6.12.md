# DeadWare 0.6.12 — Choose widget graphs

**Settings → Widget graphs** now lets you choose which graphs the widget displays: CPU/GPU usage, CPU/GPU temperature, RAM usage and Network activity. Your choices are saved and apply immediately, including while the widget is open.

All four graphs are enabled by default. Select any combination, or turn all off to show a hint instead. Hidden graphs continue collecting history.

The widget's minimum height follows the number of selected graphs. Turning graphs off keeps its current size and pin setting, so you can resize it smaller yourself. Adding graphs can expand a small widget enough to keep them readable.
