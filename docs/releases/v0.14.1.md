- Disk tracing now stops when the collector does. When DeadWare's collector stopped after an error ("Collector stopped (…). Restart DeadWare to retry."), the per-app disk trace, which runs only as administrator with Per-process monitoring on, kept running in Windows until DeadWare quit, and turning off Per-process monitoring did not stop it.
- **Open file location** no longer says a program file is gone when Windows only denies access to it: the line reads "Could not open the file location (denied by Windows)." and nothing is opened. A file Windows reports missing still reads "The program file is no longer there."
- Ctrl+F, F5 and Esc on the Processes page work right after choosing **Processes** in the sidebar: they now also work while keyboard focus is in the sidebar, in the page header or on the window itself. A menu, pop-up or other control that uses one of these keys keeps it, so with the **Color theme** menu open, Esc first closes the menu.
- `--diagnose` output no longer lists the processes that used the network (image names, PIDs and traffic); each sample gives only `NetworkApplications`, the number of processes with attributed traffic, so the report's process and network data name no apps. A report can still include hardware names, drive serial numbers and volume labels, and the message of an error it records.
- Application resources history keeps recording when two programs' names differ only in characters that are not valid Unicode; they are saved as one app with � in place of each such character, and the live Processes table still lists them apart. A program named "Everything else", or with `\`, `/` or `*` in its name, counts in Everything else, so the history file holds only image names, never paths.
- On Usage history, Left and Right on the CPU or RAM chart move one cursor, shown on both charts at the same moment, and the minute refresh keeps it where you moved it; Enter lists it. Esc and a range or period change clear it even when nothing is listed. The Application resources table keeps its selected row, current cell, keyboard focus and scroll position when the page refreshes each minute; a new ranking (another **Rank by**, range, period or listed slot) starts at the top of the table.
