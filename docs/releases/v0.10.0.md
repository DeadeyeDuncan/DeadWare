- Added **Show per-core CPU usage on usage graphs** (Settings, Monitoring; off by default). One thin line per core, tinted from the CPU graph colour, appears under the bold total on the dashboard CPU usage card, the separate CPU usage pop-out and the widget Usage graph. Hover a graph to see the eight busiest cores. Where the chip exposes threads, each thread is a line; if LibreHardwareMonitor reports no per-core loads, Windows per-processor counters are used.
- Core traces are saved in the six-hour graph history for up to 48 cores, at most once a second, so the existing file limits and older-version readability hold. Windows fallback traces are live-only when no single CPU identity is available. The joined CPU/GPU pop-out, Usage history, Alerts and Cooling Health are unchanged.

Existing updater-enabled installations can choose **Updates → Check for updates → Update & restart**.
