# DeadWare 0.6.15 — Browse release note history

The Updates tab now has a **Show release note history** button. Browse normal published versions newest first, including the installed version and older releases, even when the app is up to date.

History refreshes from GitHub each time you explicitly show it. **Hide release note history** returns to the usual current or missed-version notes. History is not fetched at startup.

Loading can be cancelled, and failed requests show a readable message with a retry option. Browsing notes does not change the offered update, download or rollback actions.
