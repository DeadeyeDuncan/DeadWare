# DeadWare 0.6.20 — GPU fan speed on temperature graphs

- Enable **Show GPU fan speed on temperature graphs** in Settings to add fan RPM to the dashboard GPU temperature graph, GPU/joined temperature pop-outs and widget temperature graph. The saved option is off by default and updates open graphs immediately.
- Show the selected GPU's first fan RPM as a dotted line in the theme's warning color (amber by default), using a separate left RPM scale while temperature keeps the right °C scale.
- Keep missing fan readings unavailable with graph gaps. A reported 0 RPM remains a valid stopped-fan reading.
- Save the last six hours of GPU fan readings across restarts, starting with this version. Earlier history has no fan readings.
