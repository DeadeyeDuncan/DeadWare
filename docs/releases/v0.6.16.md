# DeadWare 0.6.16 — Themed graph range dropdown

The six graph range buttons are now a compact dropdown on the dashboard and in each pop-out's **⋯** options menu. The dropdown follows the selected app color theme.

Choose the same **1 min**, **5 min**, **15 min**, **1 h**, **3 h** or **6 h** ranges. The selected range stays synchronized across windows and remains saved for the next session.
