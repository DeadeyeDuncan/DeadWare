- Add a **Processes** page: one row per app (processes with the same image name, expandable) with CPU, memory and I/O for every user, and Disk and Network when DeadWare runs as administrator. The default columns are CPU, Memory, I/O, Disk and Network; **PID**, **I/O read**, **I/O write**, **Disk read**, **Disk write**, **Download** and **Upload** are in the column picker, which remembers your choice.
- I/O comes from Windows' per-process I/O counters and is never disk data. A standard user sees I/O and no Disk or Network columns, and the banner reads "Disk and network need administrator".
- This is the Processes release the Storage notes called "0.12", and it answers "Per-application disk I/O … is planned for 0.12": per-app Disk ships now, for administrators. Measured on a Windows runner, 1.0051 of a 256 MB unbuffered write was credited to the writing process with no events lost, and a process scan took 0.526 ms at the 95th percentile.
- Add **End task…** for the selected process or every process of the selected app, never a process tree. It follows Task Manager's rules: it refuses System (PID 0 and 4), DeadWare itself, critical and protected processes and Windows' own processes, and it ends third-party services and other users' processes only as administrator. Windows can still deny it, reported as "denied by Windows". Otherwise it reports "Needs administrator". A box asks first, and its default answer is **No**. Known limit: any process that runs as SYSTEM or another service account from a program inside the Windows folder (outside its driver store) counts as Windows' own, so a third-party service installed there is refused as a Windows process.
- Add **Open file location** for the selected process.
- Per-process monitoring is off by default. Turn it on with **Settings → Monitoring → Per-process monitoring** or the page's **Turn on** button; while it is off, no process scan runs.
- `--diagnose` gains `--no-processes`.
- The new per-process data stays in memory; it saves or logs no process names or program paths (saved process history comes in 0.14.0). The process scan adds only counts and timings to diagnostics.
