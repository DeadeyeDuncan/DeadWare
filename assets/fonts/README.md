# Elder Scrolls theme fonts

Unmodified fonts from Google Fonts revision `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`, embedded as WPF resources. No installation or runtime downloads are needed.

- `CaesarDressing-Regular.ttf`: Caesar Dressing by Open Window, readable inscription-style English lettering. Source: https://github.com/google/fonts/blob/6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec/ofl/caesardressing/CaesarDressing-Regular.ttf
  SHA-256: `009dea24a4d4a3a7e02d683087babb1738acc0b949cce38c485fab325c9e9295`.
- `NotoSansRunic-Regular.ttf`: Noto Sans Runic by the Noto Project Authors, decorative Unicode rune glyphs. Source: https://github.com/google/fonts/blob/6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec/ofl/notosansrunic/NotoSansRunic-Regular.ttf
  SHA-256: `615b6c1166a8c51816dc1536784acbf486547e3bed03dbfdd70910e10066793b`.

Both use SIL Open Font License 1.1. Full copyright and license texts are preserved in `licenses/CAESAR-DRESSING-OFL.txt` and `licenses/NOTO-SANS-RUNIC-OFL.txt` and included in release packages. Numeric readings retain the ordinary metric font. Windows High Contrast uses the system font and omits decorative runes/texture.
