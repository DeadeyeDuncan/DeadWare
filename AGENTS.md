# DeadWare project instructions

## GitHub synchronization

- Always update GitHub when completing work that changes this project. Run the relevant checks, commit the task's changes, and push them before reporting completion; do not leave completed work only in local files or local commits.
- This is standing authorization for routine commits, pushes, and pull-request creation for requested project work. Follow the branch and pull-request workflow in `docs/development.md`.
- Fetch and inspect the current remote branch before starting changes. Preserve unrelated local work and reconcile newer remote changes without overwriting them or force-pushing.
- Verify that GitHub contains the resulting commit, and report the branch or pull-request link with the verification result.
